# Overview

* The Files extension connects to files and performs various operations.
* The Files extension supports operations such as reading CSV files and strings.
* The Files extension also supports converting mp4 files to audio files.

#### Supported File Types

The following files are supported for File Operations Area:
* CSV files (comma-separated values)
* TSV files (tab-separated values)
* PSV files (pipe-separated values)

The following files are supported for Video Area:
* MP4 file

#### Error Handling

The Files extension provides detailed error messages to help you resolve issues quickly:

* **File validation errors**: Clear messages when files don't meet format requirements
* **Data processing errors**: Specific guidance when data cannot be processed
* **System errors**: Informative messages for configuration or system-related issues

For detailed troubleshooting information, see the [Troubleshooting Guide](troubleshooting.md).

#### Note

* Extension is not supporting any entity.
