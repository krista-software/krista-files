# Extension Configuration

## Overview

The Krista Files Extension requires minimal configuration to get started. The primary configuration option is an optional file naming prefix that allows you to customize the names of generated files.

## Configuration Parameters

| Parameter | Type | Required | Description | Example |
|-----------|------|----------|-------------|---------|
| File Name Prefix | Text | No | Optional prefix for generated file names. Used when creating CSV files to provide consistent naming. | "Report", "Data_Export", "Analysis" |

### Parameter Details

#### File Name Prefix
- **Purpose**: Provides a consistent prefix for files generated by the extension
- **Default Behavior**: If not specified, files are named with timestamp: "File generated at DD-MM-YYYY HH.MM.SS AM.csv"
- **With Prefix**: Files are named as: "[Prefix] at DD-MM-YYYY HH.MM.SS AM.csv"
- **Validation**: Must contain only letters (A-Z, a-z), numbers (0-9), and periods (.)
- **Length Limit**: 1-255 characters
- **Special Characters**: Spaces and special characters are not allowed

## Step-by-Step Setup

### 1. Access Extension Configuration
1. Navigate to your Krista environment
2. Go to the Extensions section
3. Locate the "Files Extension" in the available extensions
4. Click on "Configure" or "Settings"

### 2. Configure File Name Prefix (Optional)
1. In the configuration form, locate the "File Name Prefix" field
2. Enter your desired prefix following the naming rules:
   - ✅ Valid examples: `Report`, `Data2024`, `Analysis.v1`
   - ❌ Invalid examples: `Report Data`, `Analysis-v1`, `Report@2024`
3. Leave blank if you want to use the default timestamp naming

### 3. Test Configuration
1. Click "Test Connection" to verify the configuration
2. The test should complete successfully
3. If validation fails, check that your file name prefix follows the naming rules

### 4. Save Configuration
1. Click "Save" to apply the configuration
2. The extension is now ready for use

## Authentication Type Selection

The Files Extension does not require external authentication as it operates on local file processing and uses Krista's internal file management system. No OAuth, API keys, or external service credentials are needed.

## Security Considerations

### File Handling Security
1. **File Validation**: All uploaded files are validated for type and format
2. **Size Limits**: Implement reasonable file size limits to prevent system overload
3. **File Name Sanitization**: File names are automatically sanitized to prevent security issues
4. **Temporary File Management**: Temporary files are automatically cleaned up after processing

### Best Practices
1. **Naming Convention**: Use consistent, descriptive file name prefixes
2. **Access Control**: Ensure only authorized users can access the extension
3. **File Monitoring**: Monitor file processing for unusual activity
4. **Regular Updates**: Keep the extension updated to the latest version

## Troubleshooting Configuration Issues

### Invalid File Name Error
**Problem**: "Invalid file name provided. File names can only contain letters..."

**Solutions**:
1. Remove spaces from the file name prefix
2. Remove special characters (-, @, #, etc.)
3. Use only letters, numbers, and periods
4. Ensure the prefix is between 1-255 characters

**Valid Examples**:
```
✅ "Report"
✅ "DataExport2024"
✅ "Analysis.v1"
✅ "Q4.Results"
```

**Invalid Examples**:
```
❌ "Report Data" (contains space)
❌ "Analysis-v1" (contains hyphen)
❌ "Report@2024" (contains @ symbol)
❌ "" (empty string if provided)
```

### Test Connection Fails
**Problem**: Configuration test fails during setup

**Solutions**:
1. Verify the file name prefix follows naming rules
2. Check that the Krista platform has proper file system access
3. Ensure the extension is properly installed
4. Contact your system administrator if issues persist

### Extension Not Loading
**Problem**: Files extension doesn't appear in the extensions list

**Solutions**:
1. Verify the extension is properly installed
2. Check that you have the required permissions
3. Restart the Krista service if necessary
4. Contact support for installation issues

## Advanced Configuration

### File Processing Limits
While not directly configurable through the UI, be aware of these system limits:
- **CSV File Size**: Recommended maximum 50MB for optimal performance
- **MP4 File Size**: Recommended maximum 500MB to avoid timeouts
- **Concurrent Processing**: Limited by system resources

### Performance Optimization
1. **Batch Size**: Process large datasets in smaller chunks
2. **File Format**: Use properly formatted CSV files for best performance
3. **System Resources**: Ensure adequate memory and disk space

## Validation Rules

The extension automatically validates:

| Validation | Rule | Error Message |
|------------|------|---------------|
| File Name Format | Must match `^[A-Za-z0-9.]{1,255}$` | "Invalid file name provided. File names can only contain letters..." |
| File Name Length | 1-255 characters | "Invalid file name provided. File names can only contain letters..." |
| CSV File Format | Must have .csv extension and valid CSV structure | "Invalid CSV file provided. Please ensure the file has a .csv extension..." |
| MP4 File Format | Must have .mp4 extension and valid video content | "Invalid MP4 file provided. Please ensure the file has a .mp4 extension..." |
